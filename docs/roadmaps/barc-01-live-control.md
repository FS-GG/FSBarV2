## First join: minimal live contract

The parent integrator owns one early local interface commit, landing with substantive implementation. It freezes generated bindings and test vectors before workers edit dependent surfaces. Decisions below are fixed; exact field/tag allocation and the smallest additive native transport are resolved in `.4a` against the actual caller. No implementation lane invents its own version.

1. **Explicit profile and authority.** Keep `barc-preview-v1` read-only. Add an opt-in live profile and live companion composition using the same Protocol Hub and mounted product. Authentication binds the exact origin, broker session and native perspective. A separately armed single controller binds browser identity, module hash/generation, native process/match/channel incarnation and monotonically advancing authority epoch. Capability absence refuses live arming. Existing scripting/TUI gameplay cannot compete for the controlled team; operator administration remains distinct. Never interpret arena credentials as BAR authority.
2. **Observation basis and references.** Carry the native snapshot sequence/frame, host-monotonic age/deadline policy and match identity to browser/guest and back. Carry producer-issued lifetimes for actors and selected Attack targets; tokens survive ordinary snapshots and change on death/reuse/transfer or incarnation replacement. Do not derive them from snapshot sequence or the numeric ID alone. Map bounds come from the actual installed engine API through existing StaticMap fields with qualified cell/world conversion; live UI uses those bounds, never the preview rectangle. Terrain elevation stays explicitly unknown if unavailable. Preserve the accepted fail-closed gap/recovery behavior.
3. **Semantic submission.** Guest output contains Stop, Move with explicit replace/append policy, or Attack against a visible unit reference. The trusted host adds authenticated authority, module/input identity and the guest-acknowledged basis, then submits a bounded identified parent. The broker validates all actors/targets and reserves all child/result capacity before enqueue. Native uint32 IDs are range-checked without rounding uint64 browser values. No raw AICommand/Lua/admin arms or native option bits are exposed to guests.
4. **Native final fence.** Reuse existing CommandBatch basis/generation/conflict fields wherever sufficient. Add only missing authority, target-lifetime and revocation transport/state. The current stream carries only batches and cannot acknowledge revocation: `.4a` must supply a small negotiated control/ack path that works while paused and under command saturation. A sibling versioned contract is preferred if it preserves the frozen coordinator file. A changed existing proto requires an explicit amendment and coherent producer/receiver hashes. Native monotonic expiry, process/channel replacement and epoch revocation fence queued work at dispatch. Control updates cannot wait behind ordinary queued gameplay. UI distinguishes revocation requested, native-confirmed and expired; disarm does not claim to undo orders already submitted to the engine.
5. **Result lifecycle.** Keep parent UUID, origin, child index/count, full uint64 native batch/correlation, channel incarnation, source basis/input/module identity and native frame. Expose broker admitted/refused, native admitted/rejected, dispatched/skipped and unknown separately through a bounded result stream and guest feedback. APPLIED proves dispatch, not game completion. Duplicate submission never duplicates effects; duplicate/late results never satisfy another request. Missing outcomes expire visibly without automatic retry. Define capacity and retention limits in the frozen profile.

Freeze numeric limits and temporal relationships in that commit using existing 64-unit/64 KiB/250 ms profile constraints and measured native snapshot cadence. Qualify observation-age and lease windows with a controllable monotonic clock; do not copy a simulation-frame duration into a wall-clock timeout. Reducing the supported native scenario is acceptable; silently truncating an observation or removing Attack/receiver acceptance is not.
