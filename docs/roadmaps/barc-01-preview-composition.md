# BARC-01.3 preview composition join

This local source contract joins the selected client, companion and receiver lanes. It is a product integration interface; the existing wire/guest ABI remains authoritative and unchanged.

- Fable namespace `Broker.Browser.Client`, module `BarcPreview`, exports `mount(root, options)` and returns disposal. The product and generated receiver use the same module/source. `options.assetBaseUrl` is the absolute URL to the trusted product asset root, with trailing slash. Optional `initialGatewayUrl` and `initialCredential` prefill pairing controls in memory only; empty options allow visible manual pairing. The client obtains session/profile/limits from the first authenticated WebSocket bootstrap.
- Product client owns its Fable project, entry point and Vite production build under `src/Broker.Browser.Client/`; its output is `src/Broker.Browser.Client/dist/`. All source imports stay relative to the preserved repository tree. Client owns its new lane-local manifests and exact locks; parent owns shared manifests/root solution and tool versions.
- Beneath the trusted asset root preserve `src/Broker.Browser.Wasm/**` and `src/Broker.Browser.Contracts/generated/**` unchanged. The Worker URL is `src/Broker.Browser.Wasm/guest-worker.js`, so its relative imports keep the accepted layout. Example module URLs are `guests/manual-preview.wasm` and `guests/custom-preview.wasm`. Companion SDK owner supplies those exact built bytes; fault modules stay test-only. Client configures the existing `GuestSupervisor` with the trusted Worker URL.
- Companion project `src/Broker.Browser.Preview/` composes production Protocol host, Gateway and a loopback static asset server. Explicit `--fixture` mode feeds native-shaped fixtures through public coordinator gRPC and labels the fixture in product UI. CLI supports `--assets-root`, configurable loopback ports, `--base-path` (test `/barc/`), and `--ready-file`. The ready handoff includes static URL/base, gateway endpoint, credential/session/expiry, gRPC endpoint and fixture status. Keep it in a caller-owned temporary file with mode0600; never put credential values in console logs, URLs, committed fixture data or public evidence. Gateway still authenticates its first socket frame at `/barc-preview` using the exact static origin.
- Receiver archive retains the product source/codec/Worker relative tree and guest bytes. The generated Client imports the same Fable module and sets its actual asset base URL. No rewritten BAR implementation or native assemblies enter the Fable graph. Packaging finalizes only against the joined client/companion commit and records all copied hashes.
- Real browser acceptance pairs through visible controls, receives own77/visual88/radar99/feature77/economy with known absence, selects own77, observes a subsequent complete snapshot, and emits the same guest Move to X128.25/Z-64.5 by mouse and keyboard. The labelled fixture world rectangle is explicit test geometry, not BAR map metadata. Gateway has no native command path, and final tests independently count zero submissions.

Any change to this interface returns to the parent before another lane consumes it. The owning plan defines the full validation, focus/session/generation fences and capacity limits; this join does not replace them.
